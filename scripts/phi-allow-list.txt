# scripts/phi-allow-list.txt
#
# PHI-scan allow-list: the positive declaration that a fixture's identifiers
# are synthetic. The shared PHI scan (`pnpm phi-scan`, `cosyte-phi-scan` from
# @cosyte/script-utils) reads this file; any realistic-PHI-shaped token NOT
# covered here is a hit.
#
# Format: `<TAG> <value>` per line. `#` comments and blank lines are ignored.
#   NAME <token>          synthetic person-name word, matched case-insensitively
#   DOB <value>           synthetic date of birth
#   ID <value>            synthetic id matching an SSN / MRN / member-id shape
#   EMAILDOMAIN <domain>  email domain that is allowed to appear
#
# The shared scan carries the cross-cutting floor (SSN and email shapes, raw and
# in an escape-decoded view of source literals), and it consumes EMAILDOMAIN and ID.
#   EMAILDOMAIN is GLOBAL: it switches the email detector off for that domain
#   across the whole repository.
#   ID is a WHOLE-VALUE match on the dashed-SSN check, never a pattern.
# NAME and DOB are read by field-level detectors, and this repository has none:
# its data is code systems, not patient records.
#
# To add a new synthetic fixture: reuse the tokens below, or append new ones here
# and commit. Adding a token is a reviewed, intentional act: never silent.

# --- Reserved / test email domains (RFC 2606 / 6761) ---

EMAILDOMAIN example.test

# --- Our own domain: the author address in package.json ---
